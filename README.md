# Shopping Tracker / Облік покупок

◾English: Shopping Tracker is a Python console application designed to help users organize their shopping lists, manage expenses, and keep track of their budgets. The project is developed as a learning exercise to practice fundamental Python programming concepts while building a practical application. The application aims to provide a simple way to add and remove items, view shopping lists, calculate total costs, compare expenses with a budget, and analyze shopping statistics. The project focuses on working with variables, data types, lists, mathematical operations, user input and output, conditional statements, and loops. Shopping Tracker is a beginner-friendly project that will be gradually improved and expanded with new features as development progresses.

◾Українською: Shopping Tracker — це консольний застосунок на Python, призначений для організації списків покупок, контролю витрат і керування бюджетом. Проєкт розробляється з навчальною метою та допомагає закріпити основи програмування на Python на прикладі практичного застосунку. Програма передбачає можливість додавати й видаляти товари, переглядати список покупок, обчислювати загальну вартість, порівнювати витрати з бюджетом і аналізувати статистику покупок. Під час розробки проєкту використовуються основні концепції Python, зокрема змінні, типи даних, списки, математичні операції, введення та виведення даних, умовні конструкції й цикли. Shopping Tracker — це проєкт для початківців, який поступово вдосконалюватиметься та доповнюватиметься новими функціями в процесі розробки.
